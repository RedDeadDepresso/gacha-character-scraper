# kkafio-gacha-index

- `config/commits.json` – last scraped repo commit per game (Blue Archive, Azur Lane, Zenless Zone Zero, Wuthering Waves, Arknights Endfield, Honkai Star Rail, Neverness to Everness, Nikke, Fate Grand Order, Genshin Impact, Girls Frontline 2, Pokemon, Hololive, Granblue Fantasy and Punishing Gray Raven are skipped when their source repo is unchanged).
- `scrapers/` – one scraper per gacha (Arknights, Blue Archive, Azur Lane, Uma Musume, Zenless Zone Zero, Wuthering Waves, Arknights Endfield, Honkai Star Rail, Honkai Impact 3rd, Neverness to Everness, Nikke, Fate Grand Order, Genshin Impact, Girls Frontline 2, Pokemon Masters, Hololive, Granblue Fantasy, Punishing Gray Raven, Atelier, Onmyoji). Register new ones in `main.go`.
- `config/series.json` – the list of gachas, most popular first (drives ordering in the merged index and which scrapers run). Per game: `game` (scraper / data file name), `bangumi_id` (the game's [Bangumi](https://bgm.tv) subject id, the number in `bgm.tv/subject/<id>`), the series `title` in each language (`en_us`, `zh_cn`, `zh_tw`, `ja_jp`, `ko_kr`, `ru_ru`; `en_us` defaults to the game name, so folder names stay stable) and `aliases`. Titles avoid characters that are invalid in folder names. A missing language falls back to `en_us` in KKAFIO.
- `data/<Gacha>.json` – scraped characters, newest first. `name` is an object keyed by language code (`{"en_us": "...", "ja_jp": "..."}`), `aliases` are other ways to call the character (short names, other word orders). Old files with a plain-string `name` still load; scrapers rebuild them in the new format on the next run even if the source repo is unchanged.
- `go run .` – run all scrapers locally (incremental: stops at the first already-known character) and update the Bangumi scores. The wiki blocks GitHub's IPs, so run this on your own machine and commit the updated `data/*.json`. It first downloads the [Bangumi Archive](https://github.com/bangumi/Archive) dump (about 450 MB; only `subject.jsonlines`, `subject-characters.jsonlines` and `character.jsonlines` are extracted into the git-ignored `bangumi_dump/`, and nothing is downloaded again until `aux/latest.json` changes). Flags: `-bangumi-dir`, `-no-bangumi` (do not download the dump; scores and collab flags stay as they are).
- `python scripts/merge.py` – merge `data/*.json` into `dist/gacha_character_index.json` (KKAFIO format; `pip install -r requirements.txt` first, tests: `pytest tests`). It needs no Bangumi data, only the `score` and `collab` saved in `data/*.json`. A name or series title that has a Simplified Chinese (`zh_cn`) but no Traditional Chinese (`zh_tw`) name gets one from [OpenCC](https://github.com/BYVoid/OpenCC) (`s2t`, set by `OPENCC_CONFIG` in the script).
- `.github/workflows/build-index.yml` – merges `data/*.json` and publishes to GitHub Pages on push or manual run (no scraping in CI).

Scores (set by `go run .`, saved as `score` in `data/*.json`): each character is matched by name (any language or alias, infoboxes parsed with [wiki-parser-go](https://github.com/bangumi/wiki-parser-go)) to the characters of its game's `bangumi_id` subject and scores that character's Bangumi `collects` (收藏数); characters Bangumi does not have score 0. A matched character that is a guest (`type` 3, 客串, as opposed to 1 main and 2 supporting) in the game's `bangumi_id` subject in `subject-characters.jsonlines` is a collab character: it is saved with `"collab": true` (so the incremental scrape still knows it) and the merge leaves it out. The birthday of a matched character (the `生日` field of its Bangumi infobox, e.g. `9月28日`, `9/28` or `2000-09-28`; the year is ignored) is saved as `birthMonth` and `birthDay` and copied into the index; characters Bangumi has no readable birthday for have neither. Both are logged, and a warning says when a `bangumi_id` has no characters, which means it is not the game's subject. Games without a `bangumi_id` are scored by position in `series.json`.

The merge folds alter versions (`X the Y`, `X (Y)`, `X • Y`, `X: Y`, `X・Y` or `X·Y`, where `X` exists in the same series) into the base character `X`, adding the alter's name and aliases to `X`'s aliases.

Girls Frontline 2 reads the Simplified Chinese names with [Playwright](https://github.com/playwright-community/playwright-go) (that page is built by JavaScript). Run `go mod tidy` once to fetch it; the first scrape then downloads Chromium (about 150 MB) by itself. On a Linux server, install Chromium and its system libraries first: `go run github.com/playwright-community/playwright-go/cmd/playwright@v0.6000.0 install --with-deps chromium`. If the browser cannot start, the other languages are still scraped and a warning is logged. To check the setup: `GFL2_BROWSER_TEST=1 go test ./scrapers -run RenderPageWithBrowser -v`.

`data/Gakuen Idolmaster.json` and `data/Project Sekai.json` are maintained by hand (no scraper, since new characters are rare). Keep it newest-first like the scraped files.

Index format: see KKAFIO's `06-gacha-index-format.md` (`title` / `name` per language, `"Last, First"` names). Most sources do not separate family and given names, so names are written as the source gives them; only Blue Archive (SchaleDB) is split into `"Family, Personal"` in every language. In `data/*.json` for hand-maintained games you can write `"Last, First"` names per language directly.
